# Ramu Maharajapuram — official website

Website for **Ramu Maharajapuram**, playback & concert singer (film, light music, devotional; Tamil, Telugu, Kannada, Sanskrit).

> Not to be confused with Carnatic vocalist Maharajapuram S. Ramachandran.

- Live site: https://ramumaharajapuram.com/
- Pages (served by GitHub Pages from `/docs`): Home `docs/index.html`, Story `docs/life-story/`, Music `docs/music/` (generated by `tools/build_music.py`), Watch `docs/watch/`, Press `docs/press/`, Invite `docs/invite/`. Shared styles: `docs/site.css`.
- Invitation form: https://form.jotform.com/262868493522064

## Update the site

Edit the page under `docs/`, keep the shared header identical on every page, update `docs/sitemap.xml` lastmod, then commit and push to `main`. GitHub Pages republishes in about a minute.
